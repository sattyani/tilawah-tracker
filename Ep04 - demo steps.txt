
# SCENARIO 1 — FIRST-TIME SETUP

# 1. Create a GitHub Repository

# 2. Initialize Git — Create a local Git repository.
git init

# 3. Check Status
git status

# 4. Stage Files — Prepare project files for the first commit.
git add .

# 5. Commit — Save the first version of the project.
git commit -m "Initial version of the app"

# 6. Connect to GitHub — Save the remote repository URL as origin.
git remote add origin <repository-url>

# 7. Push — Upload the local main branch to GitHub.
# git push <remote> <branch>
git push -u origin main
